{% call details({ summaryText: "What is a VTM?", classes: "nhsuk-u-margin-bottom-5" }) %}

A virtual therapeutic moiety (VTM) is an abstract representation of the substance or substances that make up a medicine, irrespective of form, strength or pack size (for example, amoxicillin or co-amoxiclav).

In reference pricing, older status, newer status and originator classification are determined at VTM level.

VTMs are used in reference pricing to identify related products and determine reference pricing information.

You can search for VTMs within the portal, to view data on products containing the same active substance(s).

Older or newer presentation

{{ table({ classes: "nhsuk-table-responsive", head: [ { text: "Name" }, { text: "Value" } ], rows: [ [ { text: "Medicine classification" }, { text: "Older medicine" } ], [ { text: "Date presentation becomes an older medicine" }, { text: "12 October 2009" } ], [ { text: "Originator status" }, { text: "Newer entrant" } ] ] }) }} {% call details({ summaryText: "How is medicine classification determined?", classes: "nhsuk-u-margin-bottom-5" }) %}

Products are classified as either an older medicine or newer medicine to determine whether they are subject to the older medicines price erosion mechanism and therefore require a reference price.

Newer Medicines

Single active substance medicines

A branded medicinal product that is an originator and either:

  • IPO data shows that a supplementary protection certificate (SPC) remains in force for the active ingredient of that VTM; or
  • it is a non-SPC scheme product (as defined in VPAG) and MHRA data (or subject matter expert review) shows that it has been no more than 12 years from the market authorisation (MA) of the first licensed presentation of the active ingredient of that VTM

Combination product

A product that is an originator and either:

  • IPO data shows that an SPC remains in force for the combination of active ingredients that make up the VTM; or
  • Where no SPC applies to that combination of active ingredients nor has one expired, lapsed or been surrendered and either:
    • IPO data shows that an SPC remains in force for any of the active ingredients (or combinations thereof) that make up the VTM; or
    • when looking only at the active ingredients to which an SPC neither applies nor has expired, lapsed or been surrendered, it has been no more than 12 years from the MA of the first licensed presentation of the most recent of the active ingredients that make up the VTM. Where the MA of the combination originator product pre-dates the MA of the first licensed presentation of the most recent of the active ingredients that make up that VTM as a single active substance, the MA of the combination originator is considered to be the date of the first licensed presentation of that ingredient.

Only originator products can be newer medicines. New entrants (non-originators) are older medicines by default.

Older Medicines

Any branded medicine that does not meet the definition of a newer medicine.

Classifications may be reviewed and updated when new information becomes available.

If a classification is not available, the product may be shown as awaiting classification.

Classifying vaccines is different from classifying other products. Refer to the reference pricing guidance for more information.

Reference anchor date

{{ table({ classes: "nhsuk-table-responsive", head: [ { text: "Name" }, { text: "Value" } ], rows: [ [ { text: "Reference anchor date" }, { text: "1 January 2008" } ] ] }) }} {% call details({ summaryText: "What is a reference anchor date?", classes: "nhsuk-u-margin-bottom-5" }) %}

A reference anchor date (RAD) is always 1 January of the calendar year before the loss of exclusivity (LOE) date of the originator.

LOE is the date when an originator medicine stops being classified as a newer medicine.

Some products may not have a RAD. In these cases, the value may be shown as No data. A RAD will be provided for these products in due course as part of regular checks.

{% call details({ summaryText: "What is an originator?" }) %}

For each virtual therapeutic moiety (VTM) we identify originator products and companies. These are used to help determine whether branded presentations are newer or older and will be used when identifying comparator branded presentations when setting reference prices.

An originator product must meet one of these criteria:

  • the branded presentation that has the earliest market authorisation (MA) date within a VTM (and any branded presentations within that VTM of the same brand name)
  • a branded presentation licensed as a new active substance (NAS) (and any branded presentations within that VTM of the same brand name)
  • a branded presentation to which an SPC applies or applied or a branded presentation of that VTM sold by a company that holds or held a valid SPC for that VTM (according to IPO data)
  • a branded presentation of that VTM sold by a company that markets or marketed a branded presentation identified as an originator
  • a branded presentation of that VTM sold by a company identified as an originator licensee (as below)

A company is an originator licensee if it either:

  • is the marketing authorisation (MA) holder for a branded presentation of that VTM licensed by an originator company prior to the originator presentation becoming an older medicine
  • was in the same corporate group as an originator company prior to an originator product becoming an older medicine and it is also the MA holder for a branded presentation of that VTM

For some VTMs, originators are not possible to identify. An unknown originator does not necessarily indicate an error.

{{ table({ firstCellIsHeader: true, classes: "nhsuk-u-margin-bottom-5", head: [ { text: "Name" }, { text: "Value" } ], rows: [ [ { text: "Date correct as of" }, { text: "12 October 2025" } ], [ { text: "Reference price type" }, { text: "List price minus 12.5%" } ], [ { text: "Reference price start date" }, { text: "15 October 2025" } ], [ { text: "Reference price end date" }, { text: "14 October 2028" } ], [ { text: "Reference price" }, { text: "£6.41" } ], [ { text: "Comparator flat price" }, { text: "Yes" } ] ] }) }} {% call details({ summaryText: "What is a reference price?", classes: "nhsuk-u-margin-bottom-5" }) %}

A reference price is a benchmark for the price at which a branded presentation was likely sold prior to the loss of exclusivity (LOE) of the originator medicine(s).

Where possible, for an originator product, the reference price is the observed average selling price at the reference anchor date (RAD). Adjusted list price data is used where average selling price data is not available.

For a new entrant, the reference price is the list price of the originator comparator (or median list price of multiple comparators) adjusted downwards by 12.5%.

£2 is the minimum reference price. This is set to align with the threshold for the low value presentation exemption.

Reference prices may be reviewed and updated over time as new information becomes available.

The reference price shown reflects the most recent information available for a product.

Comparator products used

{{ table({ classes: "nhsuk-table-responsive", head: [ { text: "Name of comparator" }, { text: "Year of comparator price" }, { text: "Comparator price" } ], rows: [ [ { text: "Adenuric 120mg tablets (28 tablet 2 × 14 tablets)" }, { text: "2023" }, { text: "£6.30" } ], [ { text: "Keral 25mg tablets (20 tablet 2 × 10 tablets)" }, { text: "2016" }, { text: "£6.30" } ], [ { text: "Migard 2.5mg tablets (6 tablets)" }, { text: "2011" }, { text: "£9.30" } ] ] }) }} {% call details({ summaryText: "What is a comparator?", classes: "nhsuk-u-margin-bottom-5" }) %}

Reference prices are set using the closest available comparator products. These are products that most closely match the branded medicine receiving a reference price and have list price or average selling price data available.

For originator products that became older medicines after 2015 DHSC will use the closest available comparator marketed by the same company (or if not available, marketed by a relevant predecessor company or a company in the same group) for which relevant average selling price data is available prior to the reference anchor date.

For originator products that became older medicines before 2015, DHSC will use the closest available comparator marketed by the same company for which relevant list price data is available.

If in either case no such comparator is available, and for a new entrant product, DHSC will use the closest available comparator marketed by any originator company for which relevant list price data is available.
