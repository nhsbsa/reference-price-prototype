All the latest information and answers to your questions.



{% call details({ summaryText: "What is a VTM?", classes: "nhsuk-expander" }) %}

A Virtual Therapeutic Moiety (VTM) is a grouping used to identify medicines that share the same active substance or therapeutic moiety.

{% endcall %} {% call details({ summaryText: "What is an originator presentation?", classes: "nhsuk-expander" }) %}

An originator presentation is the presentation used when establishing reference pricing information for a VTM.

{% endcall %} {% call details({ summaryText: "What is a Reference Anchor Date (RAD)?", classes: "nhsuk-expander" }) %}

A Reference Anchor Date is a date used within reference pricing methodology when establishing reference price information.

{% endcall %} {% call details({ summaryText: "Why can't I see an originator for a VTM?", classes: "nhsuk-expander" }) %}

Not all VTMs have an identifiable originator presentation. Where no originator can be identified, the reference pricing methodology provides alternative approaches.
